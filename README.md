## How to Distribute the Template

Before the workshop, upload `index.html` to one of the following
so participants can download it to their own device:

- A CMET Google Drive folder (shareable link)
- A public CMET GitHub repository (participants can download directly)
- A QR code linking to the raw file

Recommended: create a short URL (bit.ly or similar) that points
to the download, and display it on screen during the GitHub setup
section of the workshop.
